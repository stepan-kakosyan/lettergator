Privacy

How LetterGator protects your data

Your letters are encrypted before storage and decrypted only inside authorized application flows. We use strict access controls so each user can only interact with their own letters.

1. Encrypted storage

Letter content is encrypted at rest. Database access alone does not reveal readable message text.

2. Ownership checks

Letters are linked to your user account by user ID. Access to list, edit, and delete operations is validated against ownership.

3. Controlled preview

Message previews are available only when your letter settings allow sender preview, or after delivery according to application rules.

4. Operational security

Encryption keys are managed through server configuration and are not stored in the database alongside encrypted messages.
