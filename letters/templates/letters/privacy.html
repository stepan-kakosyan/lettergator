{% blocktrans trimmed %} Letter content is encrypted at rest. Database access alone does not reveal readable message text. {% endblocktrans %}

{% trans "2. Ownership checks" %}

{% trans "3. Controlled preview" %}

{% blocktrans trimmed %} Message previews are available only when your letter settings allow sender preview, or after delivery according to application rules. {% endblocktrans %}

{% trans "4. Operational security" %}

{% blocktrans trimmed %} Encryption keys are managed through server configuration and are not stored in the database alongside encrypted messages. {% endblocktrans %}
